注入前设置
​

WIN+R后输入：%appdata%

找到 CitizenFX 文件夹→点击 gta5_settings.xml

如若你无法打开,右键使用记事本的方法打开即可

改变FiveM屏幕设置
​

打开后使用上方编辑→查找功能搜索：<Windowed value="0" />

把0改成2即可,如果你是默认的2,则无视此步骤

注入
​

提前打开Fivem进入主页面

Fivem私服出现主界面后,进入设置→Game→勾选 NUI in-process CPU

然后以管理员运行你下载的注入器并登录

第一个是菜单

第二个是机器码

选择你需要使用的项目并点击Play注入菜单

等待下载文件

然后会出现以下提示：

然后 F1 等待菜单加载即可

在FiveM私服平台自动呼出菜单时即代表注入成功.然后你可以加入你的服务器游玩~

使用
​

点击 RSHIFT:键盘右边的Shift 呼出/隐藏菜单

鼠标点击 操控菜单
